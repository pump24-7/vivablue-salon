# Viva Blue digital design system - v0.3

Evidence: salon's own website at https://vivabluesalon.com/, viewed 2026-11-11; public blue script wordmark with yellow-centered flower and the tagline Beautiful · Brilliant · Blue.
The website-hosted official logo image is referenced at `https://vivabluesalon.com/images/33c922f60b7167724cbc786ad2dfe8c4.png` in mobile and admin. This source ZIP does **not** contain its downloadable master artwork; use a licensed owner-provided local asset before production/offline distribution.

## Palette proposal (owner approval required)

- Blue `#249CF0` for brand highlights; deep blue `#1269B3` for primary buttons
- Deep blue ink `#153C63`; lilac `#D8B3EC`; pale sky `#E5F5FF`; soft white `#F8FCFF`; daisy yellow `#F5CE39`
- Avoid old forest-green dominant identity. Keep high-contrast texts and focus states.
- Salon-approved photographs only. Website URLs remain reference assets and must not be republished without rights approval.

## Customer journey

1. Home with website-referenced official logo, bilingual toggle, editorial hero, and direct Book shortcut.
2. Services catalog -> personalized modifiers -> qualified stylist -> generated salon-local availability.
3. Approved salon-policy consent -> appointment request pending staff confirmation.
4. Lookbook -> saved favorites with consent controls -> My Viva saved looks and appointment history.
5. Events and product information; no Rewards, Club or membership upselling.

## Owner/admin journey

Organization SSO -> pending appointments -> team shifts -> catalog and modifiers -> gallery rights review -> inventory -> events -> historic finance exception review -> policies/calendar. No customer points or subscription management.
