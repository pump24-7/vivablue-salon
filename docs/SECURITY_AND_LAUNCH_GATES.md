# Security and launch gates (blocking)

1. Owner's consent to the use of Viva Blue name, branding, salon data and app store listings.
2. Obtain genuine repo/ZIP for dependency lockfiles, media assets, third-party licenses and source-provenance audit.
3. Provider-connected builds of API, mobile and admin; run database tests on real PostgreSQL 16.
4. Replace admin bearer-input interface with SSO, server-managed sessions and per-role authorization tests.
5. Confirm and seed legitimate staff qualifications and working hours; model time off, recurring closures, processing/station resources and buffers.
6. Obtain explicit service length, pricing, consultations, deposits, taxes, cancellation/refund and privacy policies.
7. Validate race conditions with PostgreSQL exclusion constraint; conduct integration tests around DST, overlapping shift definitions, staff substitutions and simultaneous bookings.
8. Add managed migrations, backups, API rate limits per identity, logs/redaction, alerting, disaster recovery and request tracing.
9. Consent-based email/SMS/push reminders, bilingual localization, unsubscribe flows, accessibility and UI QA.
10. Payment integration only after approved business terms; webhooks, retries, disputes, refunds, tips and reconciliation must be verified.
11. Review data retention, security scanning, restricted staff notes, portfolio image consent and client deletion/export.
12. Launch certification on iOS and Android physical devices, including authentication redirect URLs and network recovery.
