# Viva Blue Salon v0.2 change register (compared to v0.1)

**Rendering legend for the companion PDF:** red `-` lines are **actually removed/replaced** source lines; green `+` lines are **actually added** source lines; gray lines provide context. Whole new files appear green. Unchanged original files are listed separately. All code differences were generated by comparing source text in the actual v0.1 ZIP to the new v0.2 source tree.

## Mobile customer experience

- **CHANGED** `apps/mobile/app/index.tsx`: service-first plain list becomes branded floral, bilingual hero, lookbook media, service cards, navigation and concise account actions. Still **no email/phone fields on home screen**.
- **CHANGED** `apps/mobile/app/service.tsx`: style image preview, modifiers, look-up of approved stylist/availability, 21 salon-local date choices, consent, checkout-free appointment request.
- **CHANGED** `apps/mobile/src/theme.ts`, `app.json`, packages and environment example: upgraded palette/layout and Expo dependencies; demo-only image toggle.
- **NEW** `apps/mobile/app/lookbook.tsx`, `favorites.tsx`, `my-viva.tsx`, `memberships.tsx`, `events.tsx`, `rewards.tsx`, `shop.tsx`.
- **NEW** `apps/mobile/src/gallery.ts`, `widgets.tsx` as shared gallery references and reusable interface elements.
- **UNCHANGED/RETAINED** SecureStore OIDC PKCE client, authenticated API wrapper, booking history (with minor presentation improvements).

## API and booking

- **CHANGED** `apps/api/src/app.ts`: modifier-aware, closure-aware slots; server quote computation and acknowledgments; register new experience, media and payments routes; admin slot generator endpoint.
- **NEW** `apps/api/src/experience.ts`: lookbook, favorites, events, memberships, inventory, content moderation and team scheduling controls.
- **NEW** `apps/api/src/salon_pricing.ts`: approved local peak-pricing and modifiers in integer cents, keeping unknown prices unknown.
- **NEW** `apps/api/src/payments.ts`: optional hosted subscription payments, signed Stripe webhooks, idempotent membership/reward settlement and a finance review record.
- **NEW** `apps/api/src/media.ts`: optional signed private S3 upload, explicit user consent, HEAD confirmation and staff review.
- **NEW** pricing tests for selected modifiers/peak time. All tests still need package-resolved execution.

## Data and operations

- **NEW** migration workflow (baseline file + additive v0.2 migration) with checksum tracking and advisory locks; removes dependency on init-only Docker SQL on future updates.
- **CHANGED** `docker-compose.yml`: server starts without silently initializing an old schema; separate `npm run migrate` required.
- **CHANGED** `apps/admin/app/page.tsx`: manager token textbox removed; polished team dashboard with role-secured OIDC API proxy, appointments, shifts, slot generation, catalog, image review, modifiers, inventory, events, membership plan setup, finance review and policy approvals.
- **NEW** organization sign-in (`apps/admin/app/api/auth/*`) and encrypted session API bridge; organizational identity provider must be configured before working.
- **NEW** policy review, security, QA and operations runbooks.

## Converted from copied café-specific v0.2 language

- Cat profile / lounge / animal waiver **removed from scope** -> stylist portfolios, salon style galleries, cosmetic service consent and minor/guardian policy.
- Drink modifiers / allergens / café menu stock -> styling modifiers, hair/skin sensitivity notes, professional product ingredients and retail availability.
- Café lounge bookings -> qualified stylist slots and event capacity.
- All features that imply money, real client media or binding salon policies remain behind approval flags until owner/finance/legal review.
